# C website example
That website I made in educational purposes. It's written in C and depends only on sqlite3 and few header-only libraries. That website is made to add blog posts to my website https://me7alix.github.io

## Dependencies
 - http.h: header-only library for creating http servers
 - htmpl.h: header-only library for compiling html templates into C code
 - sqlite3: lightweight, serverless, self-contained SQL database engine

## Try it
```
make -B run
firefox https://localhost:8081
```
